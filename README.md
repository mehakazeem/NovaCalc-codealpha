# NovaCalc 🧮✨

A sleek, modern, and feature-rich scientific calculator web application built with a stunning **Dark Minimalist Monochrome** UI. Designed for both everyday calculations and complex scientific use cases with a smooth, responsive layout and live calculation history.

## 🚀 Features

* **Advanced Scientific Operations:** Support for trigonometric functions (`sin`, `cos`, `tan`), logarithms (`log`, `ln`), square roots (`√`), powers (`xʸ`), squares (`x²`), and factorials (`n!`).
* **Angle Mode Support:** Easily toggle between Degrees (**DEG**) and Radians (**RAD**) for trigonometric calculations.
* **Real-time History Panel:** Keeps track of all past calculations. Clicking any history item instantly loads it back into the calculator.
* **Modern Glassmorphism & Dark UI:** Clean, distraction-free monochrome aesthetic with smooth button hover effects and backdrop-blur styling.
* **Full Keyboard Support:** Type numbers, use operators, hit **Enter** to calculate, or press **Escape** to clear instantly using your keyboard.
* **Error Handling:** Robust expression parser that safely handles syntax errors and invalid inputs without crashing.
